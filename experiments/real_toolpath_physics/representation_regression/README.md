# Исключённый результат до исправления передачи 5D-сетки

**Не использовать для физической оценки, выбора настроек или сравнения 3D/5D.**

Эти файлы сохраняют диагностический пример: CLIParserBackend STE 7.10 сначала
разворачивал вершины по исходным индексам, затем повторно использовал эти индексы.
При индексированной сетке геометрия повреждалась; OpenSCAD отказывал в Boolean,
после чего backend молча продолжал работу с fallback-моделью.

Полученный G-code действительно записывался штатным движком, но не подтверждал
слайс исходной детали. Его объём 2.432 cm³ и соответствующий символический
оператор исключены из итоговых физических выводов. Баланс интегрирования сам по
себе не проверяет корректность поданной движку геометрии.

Исправление адаптера использует последовательные индексы тех же треугольников.
Регрессионный тест воспроизводит оба действия штатного backend и проверяет
неизменность каждого исходного треугольника. Изменять оригинальный STL или
устанавливать патч в пользовательскую копию STE не потребовалось.

`error_before_fix.json` содержит захваченный stderr OpenSCAD. Актуальные повторные
запуски находятся в соседних папках основного manifest, вне этого каталога.
