# Пресеты и переход из планирования к выполнению

Изменение интерфейса и поведения агента, 24 октября 2026. Формулы физики, правила
совместимости пресетов, подбор материала и значения настроек ядра не менялись.

Неудачный подбор материала, которому нужно сопло 0,6 мм при установленном 0,4 мм,
показывается небольшой плашкой с русской причиной. Нажатие раскрывает рекомендации.
Другие отклонённые профили передаются в сводку ядра и доступны в раскрываемом списке.
Неизвестная английская диагностика получает общее русское пояснение; оригинал
остаётся в технических подробностях вызова.

`PlanExecution` запрашивает реальный ответ пользователя перед первым действием
по готовому плану. До ответа нет применения, изменений настроек, слайсинга или
экспорта по этому плану. Отказ останавливает весь оставшийся пакет инструментов.
Согласие привязано к ID и хешу решения; другой план или область применения
«весь проект» требует соответствующего подтверждения. Предупреждение о 5D включено
в ту же карточку; флаг разрешения выставляет приложение после ответа пользователя.

Подтверждение также появляется, когда модель закончила объяснение готового плана
без вызова инструментов. Неподходящие пресеты не предлагаются к выполнению.
Вопросы с объяснениями остаются без инструментов и карточек выбора. Явные ручные
команды без расчёта ядра не требуют новой карточки перехода.

Проверки и границы доказательности:

- Agent → MCP → QuestionBox: согласие, отказ, отмена, действия одним пакетом,
  новый план, повторно открытый чат, ответ текстом, условия вместо безусловного согласия,
  предупреждения о 5D и всех моделях проекта, вопрос после отказа.
- Полный набор тестов оболочки включает транспорт семи исходных деталей организаторов
  через настоящее ядро; отдельно проверены существующие контракты native-пресетов.
- Штатная HTML/JS/CSS страница запущена в headless Edge на ширине 420 и 360 пикселей:
  русские причины, раскрытие рекомендаций, отсутствие горизонтальной прокрутки,
  отправка ответа «Остаться в планировании», отсутствие ошибок JavaScript.
- Модуль агента и проверка перехода исполнены в Python 3.5, поставляемом со STE.

Сценарий интерфейса использует локальный снимок событий и не меняет открытый проект STE.
Сценарии диалога используют программные ответы LLM; новый живой запрос Qwen для этой
проверки не выполнялся. Это проверки интерфейса и программных контрактов, а не
эксперименты о физическом качестве отпечатка.

Результаты: [software_checks.json](software_checks.json).

```powershell
python -m pytest plugin/shell_tests plugin/tests/test_presets.py -q
node plugin/shell_tests/check_preset_ui.cjs
python plugin/tools/run_py35_tests.py --script experiments/chat_execution/check_py35.py --out .runtime/plan_confirmation_py35.json
```

Для браузерной проверки нужны Node, Playwright и Edge. Playwright ищется в зависимостях
проекта или рядом с runtime Node. Путь к другому Chromium можно передать через
`STE_BROWSER`. Скриншоты и отчёт интерфейса сохраняются в игнорируемую `.runtime/preset_execution_ui`.
