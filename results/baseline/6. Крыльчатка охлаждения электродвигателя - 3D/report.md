# 6. Крыльчатка охлаждения электродвигателя - 3D

**Статус:** `needs_calibration` — кандидат, требуются калибровки/испытания и недостающие данные. Уровень доказательности: `analytical_screen`.

| Решение | Значение |
|---|---|
| Принтер | Stereotech Hybrid 530 V5.2 |
| Режим | 3D (classic) |
| Материал | Enduse PA6 (`enduse_pa6`) |
| Профиль качества | Draft (`draft`, слой 0.2 мм) |
| Ориентация | вектор модели [-0.0, -1.0, -0.0] → +Z; поворот 90° вокруг [-1.0, 0.0, 0.0] |
| Размещение | центр стола (затем arrangeAll); габарит [169.0, 169.0, 22.0] мм |

## Почему такой режим
- в задании указан 3D

## Материал
| Кандидат | Нарушено обязательных | Неизвестно | Балл |
|---|---:|---:|---:|
| Enduse PA6 | 0 | 0 | 6.6 |
| Fiberpart ABSPA G8 | 0 | 0 | 6.35 |
| Fiberpart PA12 G12 | 0 | 0 | 6.35 |
| Enduse PC | 0 | 1 | 4.75 |
| Enduse ABS | 0 | 2 | 3.4 |

Проверки выбранного материала:

- ✅ `R1` oil rating>= good — оценка класса: excellent (заявлено производителем)
- ✅ `R2` ozone rating>= good — оценка класса: good
- ✅ `R3` impact rating>= good — оценка класса: excellent (заявлено производителем)
- ❔ `R4` balance — подтверждается только испытаниями
- ✅ `R5` rigid — жёсткий
- ✅ `R6` density_g_cm3 <= 1.25 — профиль: 1.05 г/см³
- ✅ `R7` service_temp_max_c >= 70 — HDT 150…190 ≥ 80 (T+запас)

## Изменённые настройки
| Ключ | Значение | Область | Обоснование |
|---|---|---|---|
| `printing_mode` | classic | global | в задании указан 3D |
| `wall_line_count` | 5 | global | нагрузка/вращение/износ: материал у наружного контура (момент инерции сечения); t=2.0 мм → N=5 при ширине 0.4 мм [R3] |
| `top_bottom_thickness` | 2 | global | кожа не тоньше стенки: 10 слоёв по 0.20 мм |
| `infill_sparse_density` | 100 | global | ротор: однородная плотность для балансировки [R4] |
| `support_enable` | да | global | нависания 9.2% площади поверхности |
| `adhesion_type` | brim | global | склонность к короблению (PA6) или высокая деталь на малой опоре |

Температуры, обдув и ретракт — из профиля материала: сопло 260 °C, стол 100 °C, обдув 0 %, ретракт 7 мм.

## Предупреждения
- Высота слоя 0.20 мм задаётся профилем качества draft.
- Материал гигроскопичен: сушка перед печатью обязательна.

## Не хватает данных
- масса ротора и метод балансировки (класс G и г·мм не эквивалентны без массы и частоты)

## Что подтвердить испытаниями
- `R4` balance: балансировка ротора после печати
