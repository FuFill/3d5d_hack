# 7. Ось вращения передающих звёзд формовщика коробов Krones - 5D

**Статус:** `needs_calibration` — кандидат, требуются калибровки/испытания и недостающие данные. Уровень доказательности: `analytical_screen`.

| Решение | Значение |
|---|---|
| Принтер | Stereotech Hybrid 530 V5.2 |
| Режим | 5D Spiral (cylindrical) |
| Материал | Enduse PA6 (`enduse_pa6`) |
| Профиль качества | Fine (`normal`, слой 0.1 мм) |
| Ориентация | вектор модели [-0.0, -0.0, -1.0] → +Z; поворот 180° вокруг [1.0, 0.0, 0.0] |
| Размещение | ось детали совмещена с осью вращения 5D (X=0, Y=0); габарит [61.7, 23.5, 40.5] мм |

## Почему такой режим
- в задании указан 5D; у детали найдена ось вращения (доля поверхностей вращения 0.46)
- нет сквозного отверстия: ядро Ø17 мм (наименьший наружный диаметр вдоль оси) печатается классически, всё снаружи — радиальными слоями 5D Spiral
- Альтернатива `classic`: в задании указан режим 5D

Температуры, обдув и ретракт — из профиля материала: сопло 260 °C, стол 100 °C, обдув 0 %, ретракт 7 мм.

## Предупреждения
- Высота слоя 0.10 мм задаётся профилем качества normal.
- Адгезия в 5D: печать на столе: Нанести клей-адгезив на чистое обезжиренное стекло; печать на цилиндрическом основании: Наклеить малярный скотч на основание. Для изделий с толщиной меньше 3 мм - нанести на скотч клей-адгезив.
- Допуск ±0.15 мм: xy_offset не задаём (он меняет и наружный контур); нужна калибровка отверстий/контура и компенсация в CAD.
- Материал гигроскопичен: сушка перед печатью обязательна.

## Не хватает данных
- закрепление и контакт (без них напряжения по STL не определены, раздел 6)
- пара трения и условия испытания (μ определяется парой, не материалом)

## Что подтвердить испытаниями
- `R6` tolerance_mm: измерение отверстий/контура тестовой детали, калибровка компенсации
- `R7` friction_low: коэффициент трения в реальной паре (по POM)
- `R9` food_safe: подтверждение допуска материала и процесса для пищевого контакта
- `R5` surface_no_layers: подтвердить свойство по паспорту партии/испытанию (печатаемость: fair)
