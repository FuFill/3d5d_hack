# 2. Колесо конвейерной линии - 5D

**Статус:** `needs_calibration` — кандидат, требуются калибровки/испытания и недостающие данные. Уровень доказательности: `analytical_screen`.

| Решение | Значение |
|---|---|
| Принтер | Stereotech Hybrid 530 V5.2 |
| Режим | 5D Full (cylindrical_full) |
| Материал | Enduse TPU D70 (`enduse_tpu_d70`) |
| Профиль качества | Fine (`normal`, слой 0.1 мм) |
| Ориентация | вектор модели [0.0, 1.0, 0.0] → +Z; поворот 90° вокруг [1.0, 0.0, 0.0] |
| Размещение | ось детали совмещена с осью вращения 5D (X=0, Y=0); габарит [59.0, 58.99, 25.0] мм |

## Почему такой режим
- в задании указан 5D; у детали найдена ось вращения (доля поверхностей вращения 1.00)
- сквозное отверстие Ø16.0 мм ≥ 10 мм: деталь целиком печатается радиальными слоями на оправке Ø12 мм с helix-raft до Ø15.9
- Альтернатива `classic`: в задании указан режим 5D

## Предупреждения
- Наличие оправки Ø12 мм у Hybrid 530 нужно подтвердить; иначе подобрать ближайшую.
- Высота слоя 0.10 мм задаётся профилем качества normal.
- Адгезия в 5D: печать на столе: нанести клей-адгезив на чистое обезжиренное стекло; печать на цилиндрическом основании: наклеить малярный скотч на основание. Для изделий с толщиной более 3 мм - нанесите на скотч клей-адгезив
- Допуск ±0.10 мм: xy_offset не задаём (он меняет и наружный контур); нужна калибровка отверстий/контура и компенсация в CAD.
- Материал гигроскопичен: сушка перед печатью обязательна.

## Не хватает данных
- закрепление и контакт (без них напряжения по STL не определены, раздел 6)
- пара трения и условия испытания (μ определяется парой, не материалом)

## Что подтвердить испытаниями
- `R1` fatigue: циклические испытания детали/зуба на рабочем спектре нагрузки
- `R5` dust_free: износ в паре с бумагой, контроль частиц
- `R6` tolerance_mm: измерение отверстий/контура тестовой детали, калибровка компенсации
- `R7` friction_high: коэффициент трения по бумаге/крафту
- `R8` no_marks: трение по белой бумаге/картону, контроль следов
- `R9` esd: измерение поверхностного сопротивления
