# 5. Рабочее колесо насоса Wilo - 5D

**Статус:** `needs_calibration` — кандидат, требуются калибровки/испытания и недостающие данные. Уровень доказательности: `analytical_screen`.

| Решение | Значение |
|---|---|
| Принтер | Stereotech Hybrid 530 V5.2 |
| Режим | 5D Spiral (cylindrical) |
| Материал | Fiberpart PP G30 (`fiberpart_pp_g30`) |
| Профиль качества | Normal (`fast`, слой 0.15 мм) |
| Ориентация | вектор модели [-0.0, -1.0, -0.0] → +Z; поворот 90° вокруг [-1.0, 0.0, 0.0] |
| Размещение | ось детали совмещена с осью вращения 5D (X=0, Y=0); габарит [134.64, 134.65, 50.74] мм |

## Почему такой режим
- в задании указан 5D; у детали найдена ось вращения (доля поверхностей вращения 0.70)
- отверстие Ø8.0 мм меньше 10 мм: ядро Ø28 мм (наименьший наружный диаметр вдоль оси) печатается классически, всё снаружи — радиальными слоями 5D Spiral
- Альтернатива `classic`: в задании указан режим 5D

## Предупреждения
- Высота слоя 0.15 мм задаётся профилем качества fast.
- Адгезия в 5D: печать на столе: нанести клей-адгезив на чистое обезжиренное стекло; печать на цилиндрическом основании: наклеить малярный скотч на основание. Для изделий с толщиной более 3 мм - нанесите на скотч клей-адгезив
- Наполненный материал (GF30): нужно закалённое/износостойкое сопло.

## Не хватает данных
- закрепление и контакт (без них напряжения по STL не определены, раздел 6)
- масса ротора и метод балансировки (класс G и г·мм не эквивалентны без массы и частоты)

## Что подтвердить испытаниями
- `R3` cavitation: кавитационная стойкость поверхности лопастей
- `R5` fatigue: циклические испытания детали/зуба на рабочем спектре нагрузки
- `R6` creep: ползучесть при рабочей температуре и нагрузке (паз/ступица)
- `R7` balance: балансировка ротора после печати
- `R8` balance_gmm: балансировка: остаточный дисбаланс по ТЗ
- `R9` wall_variation_mm: контроль разностенности лопастей
- `R11` tensile_modulus_mpa: подтвердить свойство по паспорту партии/испытанию (типично 2600…6000 (интервал пересекает порог))
- `R12` stiffness: подтвердить свойство по паспорту партии/испытанию (типично 2600…6000 (интервал пересекает порог))
- `R13` tensile_strength_mpa: подтвердить свойство по паспорту партии/испытанию (типично 40…70 (интервал пересекает порог))
- `R14` elongation_pct: подтвердить свойство по паспорту партии/испытанию (типично 2…4 (интервал пересекает порог))
- `R15` impact: подтвердить свойство по паспорту партии/испытанию (оценка класса: fair)
- `R16` vicat_b50_c: подтвердить свойство по паспорту партии/испытанию (типично 120…150 (интервал пересекает порог))
