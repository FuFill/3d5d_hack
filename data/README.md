Дата исследования: 23 октября 2026 года.

Индекс актуализирован 24 октября 2026. Запуск, текущий API и состояние main:

## Статус разработки

Спецификация и исследования дополнены реализованным ядром, Qwen/Double ML,
функциональной механикой и адаптером установленного STE Slicer 7.10.12.
[Runtime-отчёт](../experiments/ste_runtime_report.md) отделяет реальные артефакты
слайсинга от программных свойств материала и неизвестных физических величин.
[Устойчивость к шуму и защита от утечек](research/06_robust_process_validation.md)
описывают последний этап проверки. Физическая калибровка и аттестация изделия
не выполнены. Эталонные проекты жюри не входят в материалы.

Чат/MCP из Lenaz интегрирован с исходным ядром. Модель передаётся по ID
прикрепления/объекта либо проверенному абсолютному пути; текущий transform сцены
не подменяет исходный STL. Материал/режим/физические статусы определяет ядро.
Совместимая native-база quality/variant/material наследуется по снимку каталога STE
([PRESETS.md](../plugin/PRESETS.md)).
